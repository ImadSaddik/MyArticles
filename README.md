# My articles

I store my articles in this GitHub repository using Markdown format. My aim is to back up my writings and share them with others who may find them helpful.

I chose Markdown because Large Language Models (LLMs) love it. Feel free to use these articles to quickly find information with the help of LLMs. I have no problem with that.

> [!NOTE]
> Images have been removed from the articles, as Markdown only supports linking to images rather than embedding them directly. LLMs have nothing to do with linked images.
